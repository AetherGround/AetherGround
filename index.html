Architecture

A Rust core, built for long missions.

A single service owns scheduling and the TT&C pipeline. PostgreSQL holds the mission record. The console talks to the core over REST and WebSockets.

Get started

Up in minutes.

Clone the core, bring it up with Docker Compose, and open the console. Station configuration and integration guides live in the docs.

Read the docs → 
# clone and run the core with PostgreSQL
$ git clone https://github.com/aetherground/aether-core
$ cd aether-core
$ docker compose up

# console → http://localhost:3000
